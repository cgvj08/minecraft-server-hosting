## 海外Minecraft服务器，配置怎么选才不踩坑

Minecraft这游戏有个反直觉的特点——**它吃单核性能远多于吃核心数**。一个2核5.8GHz的服务器跑MC，往往比4核3.0GHz还流畅。所以挑海外MC主机，第一眼看的是CPU单核主频，第二眼才是内存和带宽。

大致的配置参考是这样的：

- **10人以下小服/纯净服**：2核4G够用，内存主要给JVM和世界数据
- **20-50人中服/轻度模组**：4核8G起步，模组多就加内存
- **100人+大服或200+模组整合包**：6核12G以上，最好上高主频CPU
- **基岩版/群组服**：比Java版更吃资源，建议直接上4核8G以上

带宽方面，MC对上行带宽要求不算夸张，但**玩家越多、视距越大，上行消耗越明显**。10M上行带十几个玩家没问题，超过20人建议15M以上。硬盘一定要NVMe SSD，机械硬盘开MC会让TPS直接崩。
